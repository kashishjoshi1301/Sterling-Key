# Sterling Key Properties & Asset Management
> **Where Architectural Mastery Meets Unrivaled Living.**

An ultra-luxury, high-performance real estate and institutional property management web platform built on **Next.js (App Router)** and **Tailwind CSS**.

Synthesized from the world's 5 leading real estate & management platforms:
1. **The Agency RE** (`theagencyre.com`): Cinematic visual luxury, dark architectural aesthetic, narrative storytelling, and private advisory profiles.
2. **Compass** (`compass.com`): Lightning-fast multi-attribute search engine, **Interactive Map View with floating price pills**, category filter pills, interactive card carousels, and persistent client favorites.
3. **Redfin** (`redfin.com`): Interactive financial calculator with live sliders for acquisition target, down payment %, 15/30-year fixed loan terms, and a visual segmented breakdown of principal & interest, property taxes, insurance, and HOA dues.
4. **Douglas Elliman** (`elliman.com`): Prestige global flagship destinations (New York, Beverly Hills, Miami, London, Aspen), architectural provenance, and CAD vector floor plan tabs.
5. **Greystar** (`greystar.com`): Institutional property management architecture with 4 operational pillars (algorithmic yield pricing, biometric tenant vetting, 24/7 concierge maintenance dispatch, GAAP automated owner distributions) and an interactive **dual Resident & Owner Portal with real-time maintenance ticketing and ACH payment simulation**.

## 🌟 Interactive & Realistic Features Added:
- **Cinematic Auto-Playing Slideshow**: Hero background smoothly cycles through landmark estates with Ken Burns zoom effect and interactive `01 / 02 / 03` slide progress indicators.
- **Compass & Redfin Style Interactive Map View**: Toggle seamlessly between "Grid View" and "Map View". Floating interactive price pins (`$38.5M`, `$49.0M`, `$62.0M`) display instant popover cards when clicked or hovered.
- **Global Currency & Measurement Switcher**: Instant real-time conversion between **USD ($)**, **EUR (€)**, **GBP (£)**, **AED (د.إ)** and **Square Feet (SF)** vs **Square Metres (M²)** across all property cards, calculators, and modals.
- **Toast Notification System**: Real-time slide-in toasts for saving properties, copying encrypted dossier links, currency conversions, booking showings, and paying rent.
- **Multi-Tab Deep Property Modal**:
  - *Overview*: Specs, narrative, and curated estate amenities.
  - *Floor Plans & CAD Architecture*: Levels, ceiling heights, outdoor decks, and CAD schematics verification.
  - *Yield & Capital Outlay*: Projected cap rates, annual property taxes, and institutional management guarantees.
- **Greystar Resident & Owner Gateway**:
  - *Resident*: Pay monthly rent via $0-fee ACH simulation (generates real transaction ref), open emergency 24/7 maintenance dispatch tickets with category selection, and generate biometric QR key passes.
  - *Owner*: Real-time distribution ledger ($68,450 ACH), 100% occupancy tracker, and GAAP tax export.

## 🚀 Getting Started

### 1. Install Dependencies
```bash
npm install
```

### 2. Run the Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) with your browser to experience the platform.

### 3. Production Build
```bash
npm run build
npm start
```
